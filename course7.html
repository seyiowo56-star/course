Database Administration

Home / Courses / Database Administration
4 Months Professional Training Database Management

About This Course

The Database Administration programme is designed to equip students with the knowledge and practical skills required to design, manage, maintain and secure databases.

Students will learn how databases work, how to organise information, write SQL queries, create database structures and manage data efficiently. The programme also introduces database backup, recovery, security and performance monitoring.

Through practical exercises and projects, students will gain experience working with relational database management systems and handling real-world data.

What You Will Learn

  • Understand database concepts and architecture.
  • Design and create relational databases.
  • Write SQL queries to retrieve and manipulate data.
  • Create tables, views, indexes and relationships.
  • Understand database normalisation.
  • Manage database users and permissions.
  • Perform database backup and recovery.
  • Monitor and improve database performance.
  • Maintain database security and integrity.
  • Work with database management systems.

Course Requirements

Students interested in this programme should have:

  • Basic computer knowledge.
  • Basic understanding of computer applications.
  • Interest in data management and technology.
  • Willingness to practise database exercises.
  • Basic mathematics and logical reasoning skills.

Course Outline

The programme covers the following modules, progressing from database fundamentals to administration, security and practical projects.

Module 1: Introduction to Database Systems

  • Introduction to databases and database management systems.
  • Importance of databases in organisations.
  • Types of databases.
  • Database users and administrators.
  • Introduction to relational database concepts.

Module 2: Database Design and Architecture

  • Database architecture and components.
  • Understanding tables, rows and columns.
  • Primary keys and foreign keys.
  • Relationships between tables.
  • Entity Relationship Diagrams (ERD).
  • Database planning and design.

Module 3: Introduction to SQL

  • Introduction to Structured Query Language.
  • SQL syntax and commands.
  • Creating and managing databases.
  • Creating and modifying tables.
  • Data types and constraints.
  • Inserting, updating and deleting records.

Module 4: SQL Queries and Data Manipulation

  • Retrieving data using SELECT statements.
  • Filtering records with WHERE clauses.
  • Sorting and grouping data.
  • Aggregate functions.
  • Joining multiple tables.
  • Subqueries and nested queries.

Module 5: Relational Database Management Systems

  • Introduction to relational database systems.
  • Working with MySQL.
  • Introduction to Microsoft SQL Server.
  • Database creation and management.
  • Understanding database engines.
  • Connecting applications to databases.

Module 6: Database Normalisation

  • Understanding database redundancy.
  • First Normal Form (1NF).
  • Second Normal Form (2NF).
  • Third Normal Form (3NF).
  • Reducing data duplication.
  • Improving database structure.

Module 7: Database Administration

  • Roles and responsibilities of a database administrator.
  • Creating and managing database users.
  • Managing database permissions.
  • Database configuration.
  • Monitoring database activities.
  • Routine database maintenance.

Module 8: Database Security

  • Introduction to database security.
  • User authentication and authorisation.
  • Roles and access control.
  • Protecting sensitive information.
  • Preventing unauthorised database access.
  • SQL injection awareness and prevention.

Module 9: Database Backup and Recovery

  • Importance of database backups.
  • Types of database backups.
  • Creating and scheduling backups.
  • Restoring database backups.
  • Database recovery procedures.
  • Disaster recovery planning.

Module 10: Database Performance and Optimisation

  • Understanding database performance.
  • Introduction to database indexing.
  • Query optimisation.
  • Identifying slow queries.
  • Monitoring database performance.
  • Improving database efficiency.

Module 11: Advanced Database Concepts

  • Database views and stored procedures.
  • Functions and triggers.
  • Transactions and concurrency.
  • Data integrity and constraints.
  • Introduction to database replication.
  • Introduction to cloud databases.

Module 12: Practical Database Project

  • Planning a database project.
  • Designing a relational database.
  • Creating tables and relationships.
  • Writing SQL queries.
  • Managing users and permissions.
  • Backing up and restoring the database.
  • Final project presentation and assessment.

Additional Topics Covered

  • MySQL database management.
  • Microsoft SQL Server fundamentals.
  • Database documentation.
  • Database troubleshooting.
  • Data integrity and consistency.
  • Introduction to cloud database services.

Benefits of the Course

  • Gain practical database management skills.
  • Learn how to design and organise databases.
  • Develop confidence writing SQL queries.
  • Understand database security and access control.
  • Learn backup and recovery procedures.
  • Develop database troubleshooting skills.
  • Build a foundation for a career in database administration.
