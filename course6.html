.NET Developer (Full Stack)

Home / Courses / .NET Developer (Full Stack)
12 Months Professional Training Full Stack Development

About This Course

The .NET Developer (Full Stack) programme is designed to equip students with the knowledge and practical skills required to build modern software applications using Microsoft's .NET technology.

Students will learn C# programming, the .NET framework, ASP.NET, ASP.NET Core, database management and web API development. The programme also introduces software development practices that help students build secure, reliable and maintainable applications.

Through practical exercises and projects, students will gain experience working with both the front-end and back-end components of web applications.

What You Will Learn

  • Understand the .NET framework and Common Language Runtime (CLR).
  • Write programs using C# programming language.
  • Develop web applications using ASP.NET and ASP.NET Core.
  • Understand the Model-View-Controller (MVC) architecture.
  • Design and manage relational databases using SQL.
  • Build and consume Web APIs.
  • Use Entity Framework for database operations.
  • Apply security practices in application development.
  • Use Git and GitHub for version control and collaboration.
  • Test, deploy and maintain full-stack applications.

Course Requirements

To participate successfully in this programme, students should have:

  • Basic computer knowledge.
  • A Certificate Programme in Web Design.
  • Interest in programming and software development.
  • Willingness to practise and complete assigned projects.

Course Outline

The programme covers the following learning areas, combining programming fundamentals, application development and practical software projects.

Module 1: Introduction to .NET and Programming

  • Introduction to software development.
  • Understanding the .NET platform.
  • Common Language Runtime (CLR).
  • .NET libraries and development environment.
  • Setting up the development tools.

Module 2: C# Programming Fundamentals

  • Introduction to C#.
  • Variables and data types.
  • Operators and expressions.
  • Conditional statements.
  • Loops and arrays.
  • Methods and functions.

Module 3: Object-Oriented Programming with C#

  • Classes and objects.
  • Constructors and properties.
  • Encapsulation and inheritance.
  • Polymorphism and abstraction.
  • Interfaces and exception handling.

Module 4: Working with .NET Applications

  • Creating .NET projects.
  • Understanding project structure.
  • Working with collections and files.
  • Debugging and error handling.
  • Building and running applications.

Module 5: Introduction to ASP.NET

  • Introduction to ASP.NET web development.
  • Understanding client-server communication.
  • Working with web forms and web applications.
  • Handling user input and requests.
  • Building dynamic web pages.

Module 6: ASP.NET MVC and GitHub

  • Introduction to MVC architecture.
  • Models, Views and Controllers.
  • Routing and application structure.
  • Working with forms and validation.
  • Introduction to Git and GitHub.
  • Managing and sharing source code.

Module 7: Database Management with SQL

  • Introduction to relational databases.
  • Database and table creation.
  • SQL queries and data manipulation.
  • SELECT, INSERT, UPDATE and DELETE statements.
  • Primary keys and foreign keys.
  • Relationships and database design.

Module 8: ASP.NET Core

  • Introduction to ASP.NET Core.
  • Creating ASP.NET Core applications.
  • Understanding middleware and routing.
  • Dependency injection.
  • Configuration and application settings.
  • Building modern web applications.

Module 9: Web API Development

  • Introduction to RESTful services.
  • Creating ASP.NET Core Web APIs.
  • HTTP methods and status codes.
  • Working with JSON data.
  • Testing API endpoints.
  • Connecting applications to APIs.

Module 10: Entity Framework

  • Introduction to Entity Framework.
  • Object-relational mapping (ORM).
  • Database connections and migrations.
  • Working with database models.
  • Performing CRUD operations.

Module 11: Front-End and Full Stack Integration

  • Understanding front-end and back-end integration.
  • Connecting user interfaces to APIs.
  • Working with forms and validation.
  • Handling application data.
  • Integrating databases with web applications.

Module 12: Application Security

  • Introduction to web application security.
  • User authentication and authorization.
  • Input validation and data protection.
  • Secure database access.
  • Common application security risks.

Module 13: Software Testing and Quality

  • Introduction to software testing.
  • Unit testing.
  • Test-Driven Development (TDD).
  • Debugging and troubleshooting.
  • Improving application quality.

Module 14: Full Stack Application Development

  • Planning a full-stack application.
  • Building application interfaces.
  • Developing back-end functionality.
  • Connecting the application to a database.
  • Integrating front-end and back-end components.

Module 15: Deployment and Project Development

  • Preparing applications for deployment.
  • Application configuration.
  • Publishing ASP.NET Core applications.
  • Deployment and hosting fundamentals.
  • Final project development.

Module 16: Practical Project and Assessment

  • Developing a complete full-stack application.
  • Applying C# and ASP.NET Core skills.
  • Database and API integration.
  • Testing and debugging the final project.
  • Project presentation and assessment.

Additional Topics Covered

  • Entity Framework and database management.
  • Application security and user authentication.
  • Unit testing and Test-Driven Development.
  • Git and GitHub collaboration.
  • Software debugging and maintenance.
  • Application deployment and hosting.

Benefits of the Course

  • Develop practical C# programming skills.
  • Learn to build modern applications with .NET.
  • Gain experience in front-end and back-end development.
  • Understand database design and management.
  • Build and work with web APIs.
  • Develop practical software projects for your portfolio.
  • Gain a foundation for a career in software development.
